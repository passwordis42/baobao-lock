# 宝宝锁

开会或直播时锁住键盘，免得小孩乱按。鼠标和触控板照常使用。组合键解锁，长按 Esc 3 秒也可以解锁。不和专注守卫联动，开机不会自动上锁。

当前版本 **0.1.1**（Windows）。界面以医生已确认的 [UI v0](docs/design/v0/README.md) 为准，需求见 [docs/PRD.md](docs/PRD.md)。

## 怎么用

- 托盘图标：左键或右键打开菜单。未上锁是薄荷绿，已上锁是粉色。
- 上锁：`Ctrl+Alt+K`（可在设置里改）
- 解锁：`Ctrl+Alt+L`，或长按 `Esc` 满 3 秒
- 上锁后键盘（含 Alt+Tab、Win 键）会被拦住；鼠标可以拖右下角的挂件。位置会记住，也能拖到另一块屏幕。
- 解锁组合按错时，出现「哎呀，还锁着哦」，不抢焦点。提示音可关。
- `Ctrl+Alt+Del` 是系统安全桌面，拦不住。设置里写了这一点。

钩子如果没装上，会明确告诉你键盘没有锁住，并建议可以试一次「以管理员身份运行」。不会假装已经上锁。
