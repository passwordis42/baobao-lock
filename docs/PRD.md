# 宝宝锁 · 需求文档（2026-10-28·医生已拍板）

## 目标
开会/直播防小孩乱按键盘；组合键解锁；独立 Windows 小工具；不与专注守卫联动；UI 童趣；**先 UI 定稿再嵌功能**。

## 产品名
宝宝锁

## 命名（已定）
- 中文显示名 / 开始菜单：**宝宝锁**
- GitHub 仓库：`baobao-lock`
- 安装包文件名：`Baobao-Lock-Setup-x.y.z.exe`
- 进程/目录英文名：`BaobaoLock`

## 医生拍板
1. 只锁键盘（不锁触控板/鼠标）
2. 角落可拖小挂件（不要全屏）
3. 开机不自动上锁
4. 默认：上锁 Ctrl+Alt+K，解锁 Ctrl+Alt+L（可改）
5. 按错解锁：小声提示
6. 要紧急出口：定稿为「长按 Esc 满 3 秒解锁」；并说明 Ctrl+Alt+Del 系统拦不住、可作退路
7. UI 定稿后再嵌功能

## 做 / 不做
**做：** 独立安装包；上锁吞键盘；组合键上锁/解锁；角落可拖挂件（默认真屏右下、可跨屏并记位置）；快捷启动；设置（改键、提示音开关、挂件置顶）；托盘。

**不做：** 锁鼠标/触控板；全屏；开机自动上锁；联动专注守卫/日历；家长密码；macOS/移动；拦截 Ctrl+Alt+Del。

## 边界说明（写进实现）
- Alt+Tab / Win 键：上锁后一并拦截（防切窗）
- Ctrl+Alt+Del：拦不住，文案诚实告知
- 多显示器：挂件默认真屏右下，可拖到其他屏并记住
- 权限：默认不要求管理员；钩子失败时提示可「以管理员运行一次」，禁止静默假锁

## 验收（摘要）
上锁后前台收不到普通键；组合键可锁可解；鼠标触控板仍可用；挂件可拖跨屏；开机不上锁；按错有小声提示；Esc 长按 3 秒紧急解锁；与专注守卫互不影响；仅 GitHub Release 交付；UI 未批不发功能版。

## 抱娃长按上锁（2026-10-29·医生已确认 Sure · 并进 v1.0.0）

抱娃时 Ctrl+Alt+K 不好按，需要单手长按一颗常见键即可上锁。平台：Windows。

- 默认：未锁定时，长按主键盘减号 `-`（VK_OEM_MINUS）约 3 秒上锁（同一套钩子逻辑；须过诚实自检，不假锁）
- 设置：增加「长按上锁」改键项（交互同现有热键改键）；默认 `-`，可改
- 保留：Ctrl+Alt+K 上锁、Ctrl+Alt+L 解锁、Esc 长按 3 秒紧急解锁（圆环不变）
- 不做：挂件长按上锁；不补未锁态挂件；不改钩子根方案（沿用 0.1.3）；不联动专注守卫；不做多端
- UI：仅设置页一行文案/控件，无新布局、无挂件改动
- 验收：长按约 3 秒可锁、松早不上锁；上锁行为与现有一致（诚实失败仍弹窗不假锁）；原热键/紧急解锁仍有效；设置改键后新键生效、默认键不再触发（或按实现约定清空冲突）；并入 v1.0.0（托盘/关于显示 1.0.0）
- 版本：在 0.1.3 能力上叠加；#7 版本号 PR 叠本功能后再合入发版
- 交付：设置小改稿 → 医生审（可轻量）；Windows 实现并叠 #7 版本号/README 后提 PR，医生批准再合入打 v1.0.0 Release；出包后真机复验（长按 `-`、快捷键、改键）
