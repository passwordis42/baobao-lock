# 宝宝锁 · UI v0（设计稿）

**设计方向一句话：** 软萌小锁精灵守键盘——圆角奶油色卡片 + 粉/薄荷绿点缀，Windows 轻量小工具感，童趣优先、不走手绘墨线。

角色暂名「锁宝」：圆润锁身 + 腮红 + 简笔五官（原创，非现有 IP）。

## 各屏说明

| 文件 | 状态 | 主动作 / 说明 |
| --- | --- | --- |
| `widget-locked.html` + `.png` | 挂件 · 已上锁 | 角落可拖（虚线+拖点暗示）；徽章「已上锁」；提示 Ctrl+Alt+L |
| `widget-unlocking.html` + `.png` | 挂件 · 紧急解锁 | 长按 Esc 进度环（示意 1.8/3 秒） |
| `settings.html` + `.png` | 设置窗 | 改上锁/解锁键、提示音开关、挂件置顶；标题「宝宝锁」 |
| `tray-menu.html` + `.png` | 托盘右键 | 解锁 / 打开设置 / 退出；旁注锁态·开态两枚 SVG |
| `tip-wrong-key.html` + `.png` | 按错 toast | 「哎呀，还锁着哦」+ 小声波形；不抢焦点 |
